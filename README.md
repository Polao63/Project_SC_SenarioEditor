# Scenario Editor

게임 시나리오 작성자가 JSON 파일을 직접 편집하지 않고도 시나리오 데이터를 작성하고 수정할 수 있도록 만든 간단한 시나리오 에디터입니다.

Python과 PySide6를 사용하여 제작했습니다.

## 주요 기능

### 시나리오 관리

* 새 시나리오 생성
* 기존 시나리오 JSON 파일 열기
* 작성한 시나리오 JSON 파일로 저장

### 이벤트 편집

시나리오를 이벤트 단위로 추가하고 편집할 수 있습니다.

현재 지원하는 이벤트:

* Dialogue - 캐릭터 대사
* Narration - 지문
* Background - 배경 변경
* Transition - 화면 전환

이벤트의 추가 및 삭제가 가능하며, 위/아래 이동을 통해 이벤트의 순서를 변경할 수 있습니다.

### Dialogue 편집

대사 이벤트에서 다음 항목을 설정할 수 있습니다.

* 화자
* 표정
* 캐릭터 위치
* 대사 내용

### 설정값 관리

화자, 표정, 캐릭터 위치, 배경, 화면 전환 등에 사용되는 값을 에디터에서 관리할 수 있습니다.

* 새로운 설정값 추가
* 기존 설정값 수정
* 설정값 삭제

설정값은 `data/settings.json`에 저장됩니다.

## 실행 방법

### 실행 파일

배포된 폴더의 실행 파일을 실행합니다.

프로그램과 함께 제공되는 `data` 폴더는 프로그램 실행에 필요하므로 삭제하지 마세요.

```text
ScenarioEditor/
├─ ScenarioEditor.exe
└─ data/
   └─ settings.json
```

### Python에서 실행

Python 환경에서 직접 실행하려면 PySide6가 필요합니다.

```bash
pip install PySide6
```

이후 프로젝트의 Python 파일을 실행합니다.

## 사용 기술

* Python
* PySide6
* JSON
* PyInstaller

## 개발 목적

게임 개발 과정에서 시나리오 작성자가 JSON의 구조나 문법을 직접 다루지 않고 시나리오를 작성할 수 있도록 하기 위해 제작했습니다.

개발자가 사용하는 데이터 구조와 실제 시나리오 작성 과정 사이의 불편함을 줄이는 것을 목표로 하고 있습니다.

## 개발 현황

현재 기본적인 시나리오 작성 및 편집 기능을 구현한 상태입니다.

추후 필요에 따라 다음 기능을 추가하거나 개선할 예정입니다.

* 사운드 이벤트
* 화면 효과 이벤트
* 배경 리소스 관련 기능
* 시나리오 작성 편의 기능 및 UI 개선
